## 1. Описание плагина
**TextHelper** — плагин для среды разработки IntelliJ IDEA, предназначенный для быстрой обработки текста прямо в редакторе кода.

### Основные возможности:
* **Преобразование регистра:** перевод любого выделенного фрагмента текста в верхний регистр (`UPPERCASE`).
* **Анализ текста:** автоматический подсчёт количества символов в выделенном фрагменте.
* **Всплывающие уведомления:** информационное окно с результатом выполнения и подтверждением авторства.
* **Интеграция в контекстное меню:** доступ по нажатию правой кнопки мыши в редакторе кода (`EditorPopupMenu`).
* **Горячие клавиши:** поддержка быстрого вызова комбинацией `Ctrl + Alt + U`.

---

## 2. Архитектура и компоненты
Плагин построен на базе архитектуры **IntelliJ Platform SDK**:
* `src/main/resources/META-INF/plugin.xml` — файл манифеста, в котором зарегистрированы точки расширения (`Actions`), группы меню и привязка к системным событиям IDE.
* `src/main/java/org/example/ConvertCaseAction.java` — класс действия (`AnAction`), который получает доступ к редактору через `CommonDataKeys.EDITOR`, считывает выделение и безопасно модифицирует документ через транзакцию `WriteCommandAction`.
* `build.gradle.kts` — конфигурационный файл системы сборки Gradle.
